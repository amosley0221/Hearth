# Changelog

## v1.0.0

First release of Hearth.

**TV launcher**
- New home screen: clock and weather, Continue Watching, live sports strip, games strip, Modes and app dock
- Library (every installed app plus HDMI inputs), Sports (live games, My Teams, upcoming, scores), Home control (lights, thermostat, camera, lock, speakers, scenes) and Games (console wake + input switch, pinned games)
- Kids profile with approved apps, daily limit, bedtime lock and parent PIN
- Doorbell camera pop-up over any app, console waking screen, tile options, mode editor, parent controls
- One-step setup that grants every permission over ADB
- Updates itself from GitHub releases without uninstalling, started from the TV, phone or iPad

**Voice control**
- Say "play Breaking Bad", "watch The Office on Peacock", "open Netflix", "Movie Night", "lights off", "volume 20" or "put on the Eagles game"
- Finds which of your apps has a show (TMDB, using your free key) and opens that app's search for it. Continue Watching items resume directly
- Mic button and a "Voice" home-screen shortcut on the phone, Voice button on the iPad, and a Siri Shortcut ("Hey Siri, Hearth")

**Phone remote**
- Finds the TV automatically and pairs once with a code
- D-pad, volume, transport, Modes, keyboard, apps and Home Assistant controls
- Second screen: live game score and stats, now playing with progress, live games picker
- Galaxy Z Fold unfolded layout with second screen beside the pad
- Basic-remote fallback over the Android TV Remote protocol when Hearth isn't reachable
- Updates itself from GitHub releases

**iPad remote**
- Full-screen web remote served by the TV: Remote, Now, Apps + keyboard, Home, and a complete settings editor
